# IMPACT 实机 Demo 与论文实验计划

目标平台：Livox Mid-360、前视相机、下视图像/光流与测距、IMU、Orin NX、CUAV X25 MEGA，AP 4.7.1。本文是待执行方案，不是已完成实机成果。

当前核心贡献是保留共享惯性与局部平面相关项的原始像素联合融合。展示应回答：什么观测有效、何时提供帮助、失效时如何拒绝，以及这种判断是否由实际状态和独立误差支持。

## 先确认硬件输入

当前 ROS 实现接收下视原始图像，内部形成两视图像素观测。外部像素轨迹在数学上可用，但目前没有相应输入适配器。微空模块型号尚未确定：若只提供二维光流/速度、测距及质量标志，还需独立下视相机或相应算法重新设计。不能把模块速度直接接入后，仍称已部署当前原始像素模型。

当前融合接入仍含仿真相机内参、外参和测距射线常量，并按前视 epoch 的精确时间戳查下视图像/测距。实机前必须完成标定参数化和保留真实采集戳的异步关联；只发布 CameraInfo 并不会自动替换这些常量，也不能把不同时间采集的数据强改成同戳。

完整采集应包括前视/下视图像及 CameraInfo、激光雷达、实际使用的 IMU、测距、原始采集戳和接收戳、估计输出、拒绝原因、状态/协方差变化、AP DataFlash 与 MAVLink 接口日志。

## 建议拍摄顺序

| 优先级 | Demo | 场景与动作 | 需要证明什么 | 适合阶段 |
|---|---|---|---|---|
| P0 | 装机与传感器链 | 标注传感器朝向、杆臂、接口；同步显示图像、点云、测距和时间戳 | 实际型号与输入契约一致，所用数据来自机载传感器 | 装机完成即可，先无桨 |
| P0 | 无桨手持旋转与平移 | 有纹理平地，分别缓慢转动、平移，再组合运动 | 区分旋转图像运动与真实平移；检查轴向、符号、测距及有效域 | 驱动、同步、标定阶段 |
| P1 | 长走廊几何退化 | 前方结构重复、地面有纹理，往返并转弯 | 下视观测在几何较弱方向是否带来可测的帮助 | 先手持采集，再已验证的低速飞行 |
| P1 | 平移、转弯和高度变化 | 在同一有纹理平面上组合横移、转弯、升降 | 共享旋转和尺度相关项是否改变误差/协方差表现 | 有独立参考轨迹的受控区域 |
| P1 | 观测退化与恢复 | 从纹理丰富区域过渡到纹理较少区域，或在离线回放中注入明确断流 | 特征、几何或新鲜度不足时能否拒绝与恢复，避免沿用陈旧信息 | 先离线，再地面，再受控飞行 |
| P2 | 完整任务 | 起飞、定位、简单路线、停车/悬停、降落；随后加入有界复杂环境 | 新估计器确实被 AP 使用并驱动闭环，任务结果与接口证据一致 | 新融合/AP4.7.1闭环验收之后 |

不要预设完整模型必须胜出。长走廊与有纹理地面只是有辨识力的候选条件；实际差异应由数据支持。单个视频中的稳定飞行也不能证明交叉协方差模型正确。

纯旋转并不意味着所有图像都没有运动，也不自动证明深度可观测；相机杆臂会产生光学中心位移。当前实现还有最小预测平移门限，旋转演示应同时显示是否接受更新，不用“未更新”冒充估计器始终正确。

非平面、台阶及高度突变超出单一局部平面假设时，先把它们作为模型失配实验。没有实际证据前不要剪成“任意地形均鲁棒”的视频。

## 如何对比算法

第一层使用同一次硬件采集的原始 bag，离线运行原生 LIVO、联合无光流、完整模型与两个相关项消融；统一传感器记录、时间范围、标定和评估对齐。这样先隔离估计差异，再进行控制闭环比较。

第二层才比较真实闭环任务。各方法的动作会改变后续观测，应配对场景、路线、初态与预算，并报告全部重复试验。不能用不同行程的两个片段剪成同输入对照。

至少记录位置误差、轨迹/闭环终点误差、更新/拒绝计数、丢失与恢复时长、跟踪与悬停误差、处理时延及丢帧。NIS/协方差只作为声明模型下的诊断，不直接标成经过校准的完好性保护水平。

精度参考优先使用动捕或可说明误差的独立测量系统；室外可采用独立 RTK，但不能同时把同一 RTK 融入待测估计器后称为独立真值。没有独立参考时可以展示系统行为和闭环终点误差，应明确不报告未经支持的厘米级 ATE。

## 视频画面与时长

建议最终主视频 3–4 分钟：20 秒平台与核心问题、30 秒正常输入链、约 60 秒几何退化与同输入对照、约 45 秒旋转/高度变化、约 45 秒拒绝与恢复，最后给出重复实验统计与边界。

同一时轴建议显示实体外拍、前视/下视画面、点云和轨迹，以及小型状态栏。状态栏放当前方法、有效传感器、光流特征/接受状态、独立误差（有参考时）、估计延迟和 AP 模式；避免只显示漂亮地图。比较方法必须直接标明，失败和接管片段保留。任何倍速都标注倍率。

装机阶段先保存完整的无剪辑原片和原始日志，再制作论文短片。视频是一种证据展示，不能代替统计表、算法消融与可复现记录。
