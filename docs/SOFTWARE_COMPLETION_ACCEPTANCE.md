## 共同状态及消融的目标接口

当前设计候选为 **28维 = 原生19 + t0位姿clone6 + 局部plane nuisance3**。
plane为 `z=a*x+b*y+h`，高度由实际ToF射线交点构建；a/b使用已声明坡度先验，不能
从评估真值获取。两时刻原始像素经clone射线/plane交点投影至当前相机，显式处理
杆臂；不先把原始flow换成已旋转补偿的速度再冒称共享gyro相关已保留。

这些是待接入并验收的设计接口，不是当前已完成结论。像素初始端噪声、当前端噪声、
共享gyro与plane相关的传播/条件更新必须有明确数学口径。原生LIO/VIO对辅助状态的
延展需要写清固定map、独立新测量等近似；不能由一个小型线性解析控制推导出全局
非线性一致性。若实现改用其它维数/plane形式，先修订协议并保留设计变化。

正式审计至少保存：

1. 原生对象身份、源事件键、更新类型、是否接受/拒绝及原因。
2. before/after19维状态及协方差、完整28维协方差和块索引，不能只存位置均值。
3. 真实range和原始pixel batch键、像素噪声/IMU/测距使用窗口、residual、Jacobian、
   innovation covariance、gain、状态注入/reset映射，以及数值有效性。
4. gyro共享分量的单独传播/条件变换及其相关块；仅删除目标跨块的消融证据。
5. `accepted_flow_updates`、`nonzero_native_state_corrections` 与完整事件记录可互相
   核对；静止时零均值校正可以合法，但不能替代有激励场景的真实状态更新证明。

## 固定输入比较和结论规则

第一层使用同一录制/确定性生成的原始输入，对所有估计方法固定轨迹、观测、延迟与
噪声实现。前端被算法内部反馈改变时，另外列为“闭环前端变化”，不能继续声称完全
相同的观测集。第二层的AP/策略闭环可以因动作不同产生不同观测，但地图、seed、
目标、故障及计算预算需要配对，禁止把它和固定输入估计比较混成同一个因果结论。

工程串联baseline的最终实现及参数要在主验收前冻结并说明选择理由；不能故意移除其
正常旋转补偿、尺度方差或采用更陈旧数据来制造差距。full/zero_gyro/zero_scale共享
同一前端和模型参数，只改变预定相关项。比较失败/退化本身必须保留，不能只选最优
seed或把失败轨迹排除后汇总。正确性和安全门不通过需要继续修复或明确未完成；
仅“方法未优于baseline”时，可以完成软件/实验交付，但不能保留优越性声明。

统计输出以独立轨迹为单位做配对区间或cluster bootstrap；相关帧不作独立Bernoulli
试验。覆盖率按预定边缘/联合维数说明，不扩展成整任务保护级或风险保证。比较多项
假设时明确主指标，其余标为探索性或按预定方法校正。Orin延迟、热稳态、真实传感器
误差、X25实际固件和HIL/实飞均不由这些仿真统计推断。
